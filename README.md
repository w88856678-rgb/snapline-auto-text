# Snapline AutoText

复制一段文字，让它自动挂到屏幕顶部；需要时悬停展开，单击便签复制，再到聊天框或文档里粘贴原文。截图和图片也能挂在同一条绳子上，平时自动收起，方便办公时临时收集、对照和取用。

**Snapline AutoText 是非官方 macOS 定制版。** 当前版本为 **1.6.7**，在 20 项图文分页的基础上，让最近内容更好找，浏览旧内容时也能继续复制而不被打断。

## 日常怎么用

1. **收集**：在文档、网页或聊天窗口按 ⌘C 复制文字，它会自动生成便签；文字和图片合计保留最近约 20 项。
2. **取用**：将鼠标停在屏幕顶部区域展开绳子，单击文字便签，再到目标应用按 ⌘V。粘贴的是文字全文和换行。
3. **找最近内容**：启动恢复时找回最近复制的卡片。多页时用“最近复制”入口直接定位，目标卡片会显示小标签。
4. **翻看之前的内容**：使用箭头、鼠标滚轮或触控板横向滚动。正在浏览时，新复制的内容只更新“更新 N 项”提示，保留眼前卡片；点击提示后再查看最近复制。

双击便签可编辑全文，右键可固定重要内容。普通收起再展开会记住浏览位置。

## 1.6.7 的浏览体验

- **最近在前**：显示顺序为最近到更早。第 1 页展示最新一组；常见屏幕每页 7 项，20 项分为 7 / 7 / 6，卡片保留原大小。每页数量会随屏幕宽度调整。
- **浏览时保持当前位置**：新内容和重复复制的已有便签不会强制切页，也不会把其他卡片挤到鼠标下。“更新 N 项”按不同卡片计数，同一段文字多次复制不会重复累加。
- **一个入口找回最近复制**：点击“最近复制”或“更新 N 项”，定位最近捕获的卡片并清除提示。重复复制旧便签会找到它原来所在的页，不创建重复文件。
- **滚轮和横滑翻页**：在卡片或翻页控件上，鼠标滚轮向下查看更早内容、向上查看更新内容；触控板使用横向滚动，方向遵循 macOS 的滚动设置。忽略惯性连翻，同一次横向手势最多翻一页。
- **继续自动隐藏**：平时收起，顶部悬停展开，鼠标移开约 0.5 秒后收起。绳子收起时新复制内容短暂展示约 2.5 秒；首次启动提示约 6 秒。菜单打开或拖动期间保持可操作。

## 图文剪贴板功能

- **文字自动挂上**默认开启，可独立暂停；保留全文、换行和 emoji。支持普通文字、带纯文本表示的网页/Office 内容、RTF 和 URL。
- **文字便签单击复制为纯文本**。拖出文字便签时也只提供文字，不附带便签 PNG、TIFF 或文件 URL；纯文本传输格式已通过测试，真实跨应用拖拽尚未完成实机验证。
- **图片功能保留**：截图监视、图片剪贴板捕获、标注和 OCR 沿用上游。剪贴板纯图片捕获需要开启 **Catch clipboard captures**。
- **容量与固定**：图片和文字共享 20 项容量；满架时优先取下最早且未固定、也未在当前页浏览的卡片，不删除其原图或便签文件。固定项或当前浏览页都受到保护时，可临时多保留最新一项，下一次捕获替换这张临时卡片。
- **设置兼容**：重启保留固定状态、手动位置、便签全文与最近复制目标。重复复制旧便签后，重启也能定位它原来的页；目标已取下时回到最近仍挂着的卡片。可以选择在全屏应用上显示，以及是否保持展开直到内容被使用。

## 安装

支持 **macOS 14 及以上**。安装包包含 Apple Silicon 和 Intel 两种架构，使用 ad hoc 签名，尚未经过 Apple 公证。

1. 从 [Releases](https://github.com/w88856678-rgb/snapline-auto-text/releases/latest) 下载 `Snapline-AutoText-1.6.7.dmg`，将 `Snapline.app` 拖入 Applications；更新前先退出旧版。
2. 首次打开若被 macOS 拦截，在“系统设置 → 隐私与安全性”中允许打开。
3. 在菜单栏确认“复制文字自动挂上 / Auto-hang copied text”已开启。若系统询问剪贴板访问权限，允许后再复制文字。

**Control + Option + T** 可显示或隐藏绳子；若已被其他应用占用，会尝试 **Control + Option + Shift + T**，以菜单显示为准。快捷键或菜单展开后，同样会在鼠标移开、短暂预览结束后自动收起。

## 数据与隐私

数据保存在本机 `~/Library/Application Support/Snapline`，没有新增云同步。普通复制的文字会写入本地便签，不需要时可关闭文字捕获。应用跳过带系统通用 concealed / transient / autogenerated 标记的剪贴板项目，但无法保证识别所有敏感内容。

启动或重新开启捕获不会补抓此前的剪贴板内容，复制应用自己的便签也不会重复捕获。20 项是挂架的滚动工作区；容量淘汰仅取下卡片，不删除原文件。手动丢弃应用收集的文件则遵循原有废纸篓行为。

## 构建与测试

完整 Xcode 或 Command Line Tools 可用于构建。打包脚本生成 universal 应用；从仓库根目录执行：

```bash
cd macos
VERSION=1.6.7 SIGN_IDENTITY=- bash scripts/make-dmg.sh
```

产物位于 `macos/build/`：`Snapline.app`、`Snapline-1.6.7.dmg` 和 `Snapline-1.6.7-mac.zip`。`SIGN_IDENTITY=-` 强制 ad hoc 签名；发布者若需要公证，应自行配置 Developer ID 与公证流程。默认 SDK 构建失败时，脚本会尝试已安装的 macOS 26 SDK；也可通过 `SDKROOT` 指定兼容 SDK。

完整 Xcode 环境运行标准 XCTest：

```bash
cd macos
swift test
```

缺少 XCTest 的 Command Line Tools 环境，可链接真实应用 Debug 对象执行同一批测试：

```bash
cd macos
swift build -c debug --triple "$(uname -m)-apple-macosx14.0"
python3 Tests/Standalone/run.py --build-root .build
```

如需指定兼容 SDK，构建与 runner 应使用相同的 `SDKROOT`。测试使用独立剪贴板、临时文件和只读设置保护，不启动正式应用。

1.6.7 本地 Debug 与 standalone 验证通过 **65 个测试、721 个检查，0 个失败**。包括最近入口、浏览位置保护、重复便签重启定位、10 项滚动逻辑测试，以及原生滚动事件到控制器的桥接测试。

已完成 TextEdit 的实际 ⌘C 自动挂便签与单击便签后 ⌘V 粘贴纯文字。实机 GUI 验证确认：第一页最近优先，箭头可翻到更早页；满 20 项时在浏览中复制，当前七张卡片保持不变并提示更新，点击入口后定位最近卡片并显示标签。

滚轮操作的 UI 自动化工具返回 `AXError.notImplemented`；虽然事后观察到页码变化，仍不将它计为独立实机手势验证，滚动行为由逻辑与原生事件桥接测试覆盖。跨应用拖拽也尚未完成实机验证。

## CI 与来源

[GitHub Actions](https://github.com/w88856678-rgb/snapline-auto-text/actions) 在 main 推送、针对 main 的 Pull Request 或手动触发时运行 macOS 标准 `swift test`，随后构建 universal 应用并上传 DMG/ZIP。应用内版本为 **1.6.7**，main 产物标记 `1.6.7`，PR 产物标记 `dev`。CI 只有仓库读取权限，不自动创建 Release，也不构建 Windows 定制版。

新增功能仅维护 `macos/`。仓库保留上游 Windows 源码与素材供参考，不提供 Windows 定制版，也不承诺 Windows 具有上述新增功能。
