Snapline AutoText 是一个放在屏幕顶部的 macOS 图文临时工作区。查资料时复制的段落、写文档时要参考的截图，都可以挂在同一条晾衣绳上：复制文字自动生成便签，复制图片也会自动挂上，需要时按快捷键展开取用，复制和鼠标路过都不会打断工作。

![Snapline AutoText 界面示例：文字便签和图片挂在屏幕顶部，最近复制的内容带有标签](docs/autotext-recent.png)

<sub>界面示例由实际应用组件渲染，内容为虚构演示素材。</sub>

## 适合谁

- **查资料、写文档的人**：临时留住几段原文和截图，回到目标窗口就能取用。
- **需要来回对照内容的人**：把图文放在同一个挂架，查看参考内容时继续复制新材料。
- **只想整理当前任务的人**：用 20 项常规容量保留手边材料，重要内容可以固定。

## 让复制过的内容，接着用起来

| 核心功能 | 日常怎么用 |
| --- | --- |
| **复制文字自动挂便签** | 正常按 ⌘C 就能收集段落；双击便签可查看和编辑全文。 |
| **复制图片自动挂上** | 复制网页图片、截图，或 Finder 中的单张图片文件，自动挂到晾衣架上；连续复制也能各自留下。 |
| **完整原文取用** | 单击便签复制，再按 ⌘V 粘贴，保留换行和 emoji；右键也可复制文字。 |
| **图文共用挂架** | 文字便签与截图、图片一起参考；常用内容可以右键固定。 |
| **最近入口与分页浏览** | 最近内容排在前面，用标签找到刚刚复制的那项，也能翻看更早内容。 |
| **浏览时保护当前页** | 新复制项显示“更新 N 项”，眼前卡片保持原位，点击提示再查看最近内容。 |
| **主动呼出与位置记忆** | 按 ⌃⌘L 或单击菜单栏图标展开，再按一次或点击外部收起；重新打开保留浏览位置。 |

## 三步开始使用

1. **复制**：在网页、文档或聊天窗口复制文字或图片，内容会自动挂上。
2. **找到**：按 **⌃⌘L（Control + Command + L）** 或单击菜单栏图标展开挂架，找到需要的内容。
3. **粘贴**：单击便签或图片复制，在支持相应内容的目标应用按 ⌘V，继续写下去。

双击便签可以编辑全文，右键可以固定常用内容。文字与图片可分别开启或暂停；新安装默认开启自动捕获，升级会沿用原有设置。图片开关位于菜单栏和设置中的 **“复制图片自动挂上”**。

## 自动收集，主动打开

默认使用 **⌃⌘L** 显示或收起晾衣架，L 代表 Line。右键菜单栏图标进入设置，可以修改快捷键或重新查看使用引导；被占用的快捷键会明确提示，不会偷偷换键。可注册不代表不会影响其他软件，建议在常用应用中试按确认。

安装或升级后的首次打开，会提供可跳过的示例练习。示例不读取剪贴板，也不占用正式的 20 项容量。平时复制只保存到后台，鼠标经过屏幕顶部也不会弹出挂架。

## 20 项临时工作区，翻找时保持顺手

文字与图片共享 20 项常规容量，分页展示，保留卡片原来的大小。使用箭头、鼠标滚轮或触控板横向滚动，就能查看更早的内容。

正在查看旧内容时，新复制项只提示更新，不会强制跳页或挤走眼前的卡片。想看最新内容，再点击“更新 N 项”；普通收起后重新展开，仍回到刚才的位置。

## 下载与安装

支持 **macOS 14 及以上**，同一个安装包适用于 **Apple Silicon 和 Intel Mac**。

1. [下载 DMG 安装包](https://github.com/w88856678-rgb/snapline-auto-text/releases/download/v1.6.10/Snapline-AutoText-1.6.10.dmg)。更新前先退出旧版 Snapline。
2. 打开安装包，将 **Snapline.app** 拖入 **Applications（应用程序）**，再打开应用。
3. 首次打开按中文引导试一次快捷键：展开示例，再收起。可修改快捷键或稍后再试；文字与图片捕获可分别开启或暂停。

当前发行版尚未经过 Apple 公证。首次打开若被 macOS 拦截，可在 **系统设置 → 隐私与安全性** 中允许打开；若系统询问剪贴板访问权限，允许后再复制文字。

## 你可能关心

**长文字能完整保存吗？**

可以。卡片上显示预览，单击复制得到全文，双击可以查看和编辑。

**20 项满了会怎样？**

会优先取下较早、未固定且不在当前浏览页的卡片，取下不会删除原文件。固定项和浏览中的内容受到保护，必要时会临时多保留一项。这是当前任务的临时工作区，不是完整的可搜索剪贴板历史。

**内容保存在哪里？可以暂停吗？**

便签和图片保存在 Mac 本机。可以在菜单栏分别关闭文字或图片自动捕获；重新开启后，只收集之后新复制的内容。[查看数据与设置说明](docs/usage.zh-CN.md#安装数据与权限)。

**展开时会遮住页面吗？**

默认不会因鼠标经过顶部或复制内容而展开，只在后台收集并用菜单栏小圆点提示。按 **⌃⌘L** 或单击菜单栏图标才展开，此时会覆盖页面顶部区域；再次按快捷键或点击外部可收起。悬停展开可在设置中手动开启，默认关闭。

**可以把图文直接拖进聊天框吗？**

可以按住卡片向下或斜向拖出，不需要长按。便签传送完整纯文字，图片作为文件拖出；水平拖动可调整架上位置。本地 WebKit 聊天输入框已验证接收完整文字，其他应用的接收能力可能不同；也可单击复制后在目标应用按 ⌘V。
