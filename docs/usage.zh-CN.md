# Snapline AutoText 使用说明

适用于 macOS 定制版 1.6.8。它是一个自动收起的图文临时工作区：复制文字或图片，自动挂住，需要时再取用。

## 复制与取用文字

1. 在菜单栏开启“复制文字自动挂上”，正常按 ⌘C 复制文字。
2. 绳子收起时，新内容会展开提示约 2.5 秒，不弹编辑窗口，也不切换输入焦点。
3. 需要取用时，将鼠标停在屏幕顶部区域，单击文字便签，再到聊天框或文档按 ⌘V。

便签保留原始全文、换行和 emoji。长文在纸面上只显示预览，双击可编辑全文；右键 **Copy text** 同样复制原文，不使用 OCR。相同文字仍挂着时重复复制，会复用原便签。

文字拖出的数据格式为纯文字；普通图片保留图片文件拖拽方式。真实跨应用拖拽尚未完成实机验证，日常可使用已经验证的“单击复制 → ⌘V”流程。

## 复制与取用图片

1. 在菜单栏或设置中开启 **“复制图片自动挂上”**。
2. 在网页或其他应用中使用“复制图片”，复制截图，或在 Finder 中选中单张图片按 ⌘C。实际图片内容会自动保存并挂上，不需要先另存到桌面。
3. 展开挂架，单击图片复制，再到支持图片粘贴的应用按 ⌘V；图片也可按原有方式拖出。

支持常见 PNG、JPEG、TIFF 图片。浏览器附带的网址或 HTML 不会另外生成文字便签；仅复制“图片地址”时仍是一段文字，不会自动下载远程图片。Finder 一次复制多张图片暂不自动收集，动图按静态首帧保存。

连续复制不同图片时会分别保留；图片后紧接着复制文字也不会丢掉前一张已捕获的图片。同一次截图同时保存文件和进入剪贴板时，会按图片内容避免重复挂上，不会仅因两张图片大小相同就忽略其中一张。

新安装默认开启文字与图片自动捕获，升级沿用原来的开关状态。关闭图片捕获不影响文字便签；重新开启不补抓之前的剪贴板内容。单击架上图片取用，也不会再次生成一张卡片。

## 找到最新或更早的内容

显示顺序为**最近到更早**。重启会找回最近复制的卡片；通常在最新一页，但最近复制的是已有旧便签时，会回到它原来所在的较早页。普通收起再展开则记住上次浏览位置。

- **箭头翻页**：向左查看更新内容，向右查看更早内容。
- **鼠标滚轮**：鼠标位于卡片或翻页控件上时，向下查看更早内容，向上查看更新内容。
- **触控板横向滚动**：在同一区域横向滚动翻页，方向遵循 macOS 的滚动设置；同一次手势最多翻一页，惯性不会连续翻页。触控板纵向滚动不作为翻页操作。
- **最近复制**：多页时点击这个入口，找到最近捕获的卡片；目标卡片有小标签辅助辨认。

只有一页时不需要翻页，滚动不会切页。

## 浏览时继续复制

绳子已经展开、你正在浏览时，新复制的内容不会强制切页，眼前的卡片也不会被其他页的内容挤走。入口会显示 **“更新 N 项”**；点击后定位最近复制的卡片，并清除更新提示。

N 统计不同卡片，不统计复制次数。例如，同一段文字连续复制三次，只计作一项更新。重复复制已有便签也会被提示，点击入口可以找到它原来所在的页。

普通隐藏再展开会保留浏览位置；绳子收起后再次捕获新内容，则重新跟随最近捕获的卡片。

## 20 项与固定内容

图片和文字共享 20 项容量。每页数量随屏幕宽度调整；常见屏幕每页 7 项，20 项分成 7 / 7 / 6，卡片保持原大小。

满架时优先取下最早且未固定、也未在当前页浏览的卡片。容量淘汰只从挂架取下，不删除原图或便签文件。右键 **Keep on the line** 可固定重要内容。

当前浏览页与固定项都受到保护；没有可淘汰项时，允许临时保留一张最新卡片，下一次新捕获替换这张临时卡片。重启保留便签全文、固定状态、手动位置与最近复制目标；目标已取下时回到最近仍挂着的卡片。

20 项是日常取用的滚动工作区，不是完整的可搜索历史归档。手动丢弃应用收集的文件仍会使用原有废纸篓行为。

## 自动隐藏与设置

菜单、便签颜色、设置和翻页提示支持简体中文。中文系统会自动匹配，也可以在 **设置 → 语言 → 简体中文** 中选择。

平时绳子收起，将鼠标停在屏幕顶部区域时展开；移开约 0.5 秒后收起。首次启动提示约 6 秒后结束。菜单打开或拖动期间会保持可操作。

展开的挂架会覆盖页面顶部区域；目前仍会在顶部悬停时展开，收起时新复制内容也会短暂展开提示。

**Control + Option + T** 可显示或隐藏；快捷键被占用时会尝试 **Control + Option + Shift + T**，以菜单实际显示为准。菜单或快捷键展开后仍遵循自动收起规则。

可按需开启：

- **保持展开直到内容被使用**：未取用的新内容会保持展开。
- **在全屏应用上显示 / Show over full screen apps**：允许在全屏窗口上使用绳子，默认关闭。
- **复制图片自动挂上**：捕获复制的图片；新安装默认开启，升级沿用原有选择。截图监视功能仍可单独使用。

## 安装、数据与权限

支持 macOS 14 及以上，安装包包含 Apple Silicon 与 Intel 两种架构。从 [Releases](https://github.com/w88856678-rgb/snapline-auto-text/releases/latest) 下载 `Snapline-AutoText-1.6.8.dmg`，退出旧版后将 `Snapline.app` 拖入 Applications。

构建使用 ad hoc 签名，尚未经过 Apple 公证。首次打开若被拦截，可在“系统设置 → 隐私与安全性”中允许打开。若 macOS 询问剪贴板访问权限，允许后再复制文字。

数据保存在本机 `~/Library/Application Support/Snapline`。不需要保存复制的文字或图片时，可分别关闭对应捕获开关；重新开启只捕获之后的新复制内容，不补抓此前的剪贴板。应用自身复制便签或图片不会产生重复卡片。

本项目为非官方 macOS 定制，基于 [Snapline v1.6.2](https://github.com/mohabujubara/snapline/tree/v1.6.2) 及 [Tendedero](https://github.com/alejandrobujan/tendedero)，保留 [MIT 许可证](../LICENSE) 与版权声明。
